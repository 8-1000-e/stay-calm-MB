# Setup notes

## Bolt build

The workspace is configured to use:
- `bolt-lang` from git main (`patches/session-keys/` patch applied via `[patch.crates-io]` in root `Cargo.toml`)
- Cargo.lock pinned from trade-fight to avoid `indexmap v2.14.0` (which requires `edition2024` not stabilized on Rust 1.84)

Build:
```bash
cd /Users/emile/Documents/TNTX/stay-calm
bolt build
```

Output: `target/deploy/<program>.so` and `target/deploy/<program>-keypair.json` for each program.

## Cargo.lock workaround

If a fresh `cargo update` ever pulls `indexmap v2.14.0` and breaks the build with:
```
feature `edition2024` is required
```
Restore from trade-fight:
```bash
cp /Users/emile/Documents/TNTX/trade-fight/Cargo.lock Cargo.lock
bolt build
```
